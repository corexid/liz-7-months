## GitHub Pages

1. Создайте GitHub-репозиторий и добавьте файлы проекта вместе с фотографиями.
2. Откройте репозитория **Settings → Pages**.
3. В разделе сборки выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните настройки. GitHub Pages покажет адрес опубликованного сайта на этой же странице.

Сайт работает как обычный статический HTML и не требует `npm install` или сборки.
